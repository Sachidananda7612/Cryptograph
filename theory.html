Mathematical Theory of RSA

The RSA Cryptosystem is an asymmetric algorithm based on the computational difficulty of prime factorization. It uses two separate keys: a Public Key (e, n) available to everyone for encryption, and a Private Key (d, n) kept secret by the receiver for decryption.

1. Selection of Primes and Modulus

Select two large distinct prime numbers p and q. Compute the RSA modulus:

n = p × q

The modulus n is published as part of both the public and private keys. Its bit-length defines the cryptographic key strength.

2. Euler's Totient Function φ(n)

Euler's totient function counts the positive integers up to n that are relatively prime (coprime) to n:

φ(n) = (p - 1) × (q - 1)

3. Public Exponent Selection (e)

Select an integer e (the public exponent) such that:

  • 1 < e < φ(n)
  • gcd(e, φ(n)) = 1 (e and φ(n) must be coprime)

4. Private Exponent Calculation (d)

The private exponent d is the modular multiplicative inverse of e modulo φ(n):

e × d ≡ 1 mod φ(n)   ⟺   d = e⁻¹ mod φ(n)

This is computed using the Extended Euclidean Algorithm.

5. Encryption and Decryption Formulas

For any plaintext numeric key M satisfying 0 ≤ M < n:

  • Encryption: C = M^e mod n
  • Decryption: M' = C^d mod n
